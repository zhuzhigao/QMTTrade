# PB 低估值子策略（kj202512_pb）

> 在全 A 股中筛选 PB 极低（< 0.98）且 ROE 持续高增长的个股，以格雷厄姆式深度价值逻辑月度换仓，持仓 1 只。

## 策略总述

### 选股宇宙

全 A 股（沪深主板 + 创业板），逐层过滤后进入财务筛选：

1. 排除科创板（68x 开头）和北交所（.BJ / 4xx / 8xx 开头）
2. 排除 ST / \*ST / 退市风险股
3. 排除停牌股（前一日成交量为 0）
4. 排除次新股（上市不足 365 天）
5. 排除金融行业（名称含"银行 / 证券 / 保险 / 信托 / 期货"）——金融股 PB < 1 是行业常态，无选股意义

### 核心信号：五重财务门槛

| 条件 | 阈值 | 字段 | 说明 |
|------|------|------|------|
| PB | < 0.98 | `price / s_fa_bps` | 股价低于每股净资产，资产折价买入 |
| ROE | > 15% | `equity_roe` | 净资产回报率高，资产质量有保障 |
| EPS | > 0 | `s_fa_eps_basic` | 当期每股盈利为正 |
| 净利润 | > 0 | `net_profit_incl_min_int_inc_after` | 排除净亏损公司 |
| 净利润同比 | 连续两期为正且增长 | 同上（比较前后两期） | 排除业绩恶化及扭亏为盈的反转陷阱 |

财务数据取最近两年（动态起始日 = 当前日期往前推 730 天），确保始终使用最新披露数据。

### 完整选股流程

```
Step 1  基础过滤（KCBJ / ST / 停牌 / 次新股 / 金融行业）
Step 2  获取财务数据（PershareIndex + Income，730 天滚动窗口）
Step 3  五重财务条件逐一过滤
Step 4  按 ROE 降序排列，取前 3 只候选
Step 5  涨停 / 跌停过滤（已持仓股保留，未持仓涨跌停股剔除）
Step 6  输出最终选股列表（最多 1 只进入持仓）
```

### 调仓执行

- **先卖后买**：卖出不在目标列表的持仓 → 等待成交确认 → 买入新标的
- **等权买入**：可用资金 = `min(账户现金, 16,000 元)`，一次性全仓买入 1 只
- **按手数下单**：`volume = int(预算 / 价格 / 100) * 100`，不足 100 股跳过

### 风控机制

| 机制 | 触发条件 | 处理方式 |
|------|----------|----------|
| 个股止损 | 持仓跌幅 ≥ 15%（相对买入均价） | 市价清仓，进入 28 日历天静默期 |
| 涨停打开卖出 | 昨日涨停，今日盘中打开 | 14:00 / 14:50 两档巡检，打开即卖 |
| 止损静默期 | 止损后 28 天内 | 跳过止损检查，不建新仓 |

## 策略优势、劣势与适用市场环境

### 优势

- **安全边际充足**：PB < 0.98 意味着以低于净资产的价格买入，理论上破产清算也能保本
- **质量过滤严格**：ROE > 15% + EPS > 0 + 净利润同比增长，排除了大多数价值陷阱
- **金融行业隔离**：主动排除银行保险等 PB 天然低的行业，避免误判
- **逻辑简单稳定**：纯财务因子驱动，不依赖预测或复杂模型，不容易过拟合

### 劣势 / 风险

- **持仓极度集中**：只持 1 只股票，单股黑天鹅可造成策略净值大幅回撤
- **ROE 非 ROA**：xtquant 无直接 ROA 字段，用 ROE 替代会放入部分高杠杆公司
- **财报滞后**：A 股财报最长可滞后 4 个月披露，选股时用到的可能不是最新季报
- **价值陷阱风险**：低 PB 股可能长期无催化剂，资金长时间被占用

### 适合的市场环境

- **最佳**：低利率、价值风格占优、市场整体估值低位的环境（如 2014、2022 年末）
- **一般**：震荡市，价值股防御性相对较好
- **不适合**：成长风格极度强势的牛市（如 2020–2021 科技牛），低 PB 股会显著跑输指数

## 主要参数

| 参数名 | 默认值 | 说明 | 调整建议 |
|--------|--------|------|----------|
| `TOTAL_BUDGET` | 16,000 元 | 策略资金上限（占总盘 8 万的 20%） | 根据账户规模等比调整 |
| `MAX_HOLD` | 1 | 最大同时持仓数 | 提高至 2~3 可降低集中度风险 |
| `MAX_SELECT` | 3 | ROE 排序后保留的候选数 | 与 MAX_HOLD 保持 2~3 倍关系 |
| `STOPLOSS_LEVEL` | 0.15 | 个股止损阈值（跌幅） | 可在 0.10~0.20 之间根据风险偏好调整 |
| `STOPLOSS_SILENCE_DAYS` | 28 天 | 止损后静默期（继承自基类） | 约等于 20 个交易日，不建议缩短 |
| `min_days`（次新股） | 365 天 | 上市满多少天才入选 | 保守可提高至 730 天 |
| PB 阈值 | < 0.98 | 市净率上限 | 放宽至 1.2 可显著扩大候选池，但安全边际降低 |
| ROE 阈值 | > 15% | 净资产回报率下限 | 降低至 10% 可扩大候选池，但质量把关变松 |

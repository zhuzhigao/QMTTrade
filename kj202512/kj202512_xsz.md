# 小市值多因子策略（kj202512-XSZ）

> 从全 A 股中通过三组因子并集筛选高质量小市值股票，每周一等权买入，持仓 2 只。

## 策略总述

### 选股宇宙

全 A 股（沪深主板 + 中小板 + 创业板），排除：
- 科创板（68x.SH）、北交所（.BJ / 4xx / 8xx）
- ST / \*ST / 退市风险股
- 上市不足 400 天的次新股
- 前一交易日停牌（成交量为 0）的股票

### 三组因子选股

每组对候选股做 **百分位 rank 归一化**（消除量纲差异），取各组得分前 10% 的股票，三组取并集。

| 组别 | 因子 | 权重 | 方向 |
|------|------|------|------|
| 组1 质量因子 | ROE | 50% | 高值优先 |
| | 净利润率（净利润/营收） | 30% | 高值优先 |
| | EPS（每股收益） | 20% | 高值优先 |
| 组2 动量反转 | 252日价格动量（close/MA252-1） | 40% | **低值优先**（反转效应） |
| | 净利润同比增速 | 40% | 高值优先 |
| | 资产负债率（D/A） | 20% | 低值优先 |
| 组3 低负债质量 | 资产负债率（D/A） | 60% | 低值优先 |
| | 净利润率 | 40% | 高值优先 |

所有组均要求 EPS > 0（盈利股）。

净利润增速特殊处理：
- 上期盈利 → 正常计算同比增速
- 由亏转盈 → 赋值 +1.0（视为高增速）
- 持续亏损 → 赋值 -0.5（视为负增速）

### 完整选股流程

1. 基础过滤（ST、次新、停牌）→ 通常剩 3500~4000 只
2. 批量获取财务数据（PershareIndex / Income / Balance，分批每次 200 只）
3. 批量下载 253 日历史收盘价，计算价格动量
4. 构建因子 DataFrame，对三组各自做 rank 归一化 + 加权打分
5. 三组各取前 10%，合并取并集（通常约 400~600 只）
6. 按总市值（当前价 × 总股本）升序，取前 4 只候选
7. 过滤当日涨停 / 跌停股（已持仓的保留）
8. 最终目标持仓不超过 2 只

### 调仓执行

- **先卖后买**：卖出不在目标列表的持仓，等待成交后再买入新标的
- **等权买入**：可用预算 = min(现金, 总预算 - 已持仓市值)，均摊到新买入标的
- **最小手数**：不足 100 股则跳过

### 风控机制

| 机制 | 触发条件 | 处置 |
|------|----------|------|
| 个股止损 | 持仓均价跌幅 ≥ 20% | 卖出触发股，进入 28 天静默期（期间不新建仓位，但仍继续止损巡检） |
| 空仓月 | 4 月 | 月初 09:31 清仓本策略全部持仓 |
| 涨停打开 | 昨日涨停、今日打开 | 14:00 / 14:50 两次巡检，确认后卖出 |

## 策略优势、劣势与适用市场环境

### 优势

- **多因子并集**：质量、动量反转、低负债三个维度各自独立选股，降低单因子失效风险
- **反转因子捕捉超跌机会**：小市值 + 价格反转是 A 股经典有效因子组合
- **严格盈利过滤**：EPS > 0 要求排除亏损股，叠加低负债约束，避免垃圾小市值陷阱
- **rank 归一化**：消除因子量纲差异，防止高 EPS 大蓝筹干扰小市值筛选

### 劣势 / 风险

- **持仓集中**：仅持 2 只股票，单股黑天鹅事件对净值影响极大
- **小市值流动性风险**：极端行情下可能出现连续跌停无法止损
- **财务数据滞后**：使用公告时间（announce_time）的最新报告期数据，可能存在 1~3 个月滞后
- **周频换手摩擦**：每周调仓，若持仓频繁替换会累积较高交易成本

### 适合的市场环境

- **最佳**：A 股小市值风格占优时期（市场偏好高弹性、高成长小盘股）
- **次佳**：震荡市中有结构性行情（某些行业小市值轮动）
- **不适合**：大盘蓝筹主导的单边牛市（小市值跑输），以及流动性枯竭的熊市底部

## 主要参数

| 参数名 | 默认值 | 说明 | 调整建议 |
|--------|--------|------|----------|
| `TOTAL_BUDGET` | 24,000 元 | 策略资金上限 | 根据账户规模等比调整 |
| `MAX_HOLD` | 2 | 最大同时持仓数 | 提高至 3~5 可降低集中度风险，但会摊薄收益 |
| `MAX_SELECT` | 4 | 市值排序后保留的候选数 | 建议保持 MAX_HOLD 的 2 倍 |
| `NEW_DAYS` | 400 天 | 次新股过滤阈值 | 提高可进一步排除炒作新股 |
| `TOP_PCT` | 10% | 每组取前 N% | 降低可提高选股质量，但并集变小，多样性下降 |
| `STOPLOSS_LEVEL` | 20% | 止损触发跌幅 | 小市值波动大，不建议低于 15% |
| `STOPLOSS_SILENCE_DAYS` | 28 天 | 止损后静默天数 | 约 20 个交易日，避免频繁止损再建仓 |
| `EMPTY_MONTHS` | [4] | 空仓月份列表 | 4 月为年报披露高峰，雷股风险大 |

## 推荐调仓周期与运行时间

| 操作 | 触发条件 | 时间窗口 | 说明 |
|------|----------|----------|------|
| 空仓月清仓 | 4 月首个交易日 | 09:31~09:34 | 防重入，本月只执行一次 |
| 选股 + 调仓 | 每周一（非空仓月、非静默期） | 09:35 起 | 先卖后买，等待成交后再下买单 |
| 涨停打开巡检 | 每日 | 14:00~14:02 | 昨日涨停今日打开则卖出 |
| 涨停打开巡检 | 每日 | 14:50~14:52 | 尾盘二次确认 |
| 止损巡检 | 每日 | 14:45~14:55 | 跌幅 ≥ 20% 即触发，静默期内仍继续巡检 |

## 运行方式

```bash
# 调试模式（完整跑选股逻辑，打印日志，不发真实报单）
python kj202512_xsz.py

# 实盘模式（谨慎！确认逻辑正确后使用）
python kj202512_xsz.py -m REAL
```

状态与持仓文件（运行时自动生成）：

- `kj202512/xsz_state.json` — 调仓周次、止损日期、空仓月记录等
- `kj202512/xsz_holdings.json` — 本策略持仓账本（与其他策略隔离）
